# MOVE≡FIT — website demo

A single-file, responsive landing-page concept for the MOVE≡FIT gym in La Marsa.

## Preview
Enable GitHub Pages from **Settings → Pages → Deploy from a branch → main → /(root)**, then open the published Pages URL.

## Included
- French-first one-page site with responsive mobile navigation
- Charcoal / white / orange visual direction based on the Instagram references supplied for this demo
- Intro, atmosphere gallery, membership information, opening hours, and contact sections
- Instagram contact links to [@movefit_tn](https://www.instagram.com/movefit_tn/)
- CSS motion effects, reveal-on-scroll animations, reduced-motion support, and accessible navigation labels
- All HTML, CSS, and JavaScript contained in `index.html`

## Important before publishing for the business
This is an unofficial concept demo. It is not an approved MOVE≡FIT website.
- Membership prices, previous prices, the TND 25 registration fee, and opening hours were transcribed from screenshots supplied for the concept. The screenshots may describe a launch offer, so confirm all details with the club before using this publicly.
- The gym photography is illustrative external stock imagery, not verified photos of MOVE≡FIT. Replace it with images supplied or approved by the club.
- The only contact destination currently configured is the public Instagram profile. No telephone number, street address, booking form, or payment functionality has been invented or added.
- Confirm the club's permission to use its name and logo treatment before making the site public as an official business website.

## Local preview
Open `index.html` in a modern browser. Internet access is needed for Google Fonts and the remote illustrative photos.
